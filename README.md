# House Price Prediction

A regression example estimating residential sale prices from property characteristics.

## Workflow
- Explore a synthetic housing dataset.
- Split training and test data.
- Preprocess numeric and categorical features.
- Compare a mean baseline, linear regression and random forest.
- Evaluate with MAE, RMSE and R-squared.

## Run
```bash
pip install -r requirements.txt
python src/train.py
```
Metrics are generated locally. The supplied data is synthetic and not suitable for real-estate decisions.
